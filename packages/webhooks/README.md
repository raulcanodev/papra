# Paqui webhooks

This package is used to trigger and easily consume webhooks from Paqui.

## Installation

```bash
# using pnpm
pnpm add @paqui/webhooks

# using npm
npm install @paqui/webhooks

# using yarn
yarn add @paqui/webhooks
```
